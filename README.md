# C++ Inheritance & Polymorphism Engine

A C++ application demonstrating object-oriented inheritance, virtual functions, method overriding, and runtime polymorphism using base class pointers and vectors.

## C++ Concepts Covered
* **Inheritance**: Deriving specialized classes (`Manager`, `Developer`) from a common base class (`Employee`).
* **Virtual Functions & `override`**: Ensuring dynamic method dispatch at runtime.
* **Polymorphism**: Managing diverse derived objects uniformly through base class pointers.
* **Virtual Destructors**: Preventing resource leaks during polymorphic object deletion.

## How to Compile & Run
```bash
g++ main.cpp -o polymorphism_engine
./polymorphism_engine
